# Keyboard shortcuts

Everything in the console can be done with a mouse. These shortcuts are faster. Press `?` at any time to see the list in the console itself.

On Linux and Windows `mod` means `Ctrl`; on a Mac it means `Cmd`.

## Search and help

| Keys | Does |
|---|---|
| `mod+k` | Opens the command palette. It searches sandboxes, nodes, models, policies, sites, data centers, clusters, jobs and the documentation. |
| `?` | Shows the shortcuts sheet. |
| `Esc` | Closes the palette, a dialog, a drawer or the sheet. |

In the palette: type to search, use the filter chips to narrow by kind, data center or status, move with the arrow keys and press `Enter` to open.

## Go to a page

Press `g`, release it, then the second key within about one second.

| Keys | Opens |
|---|---|
| `g h` | Home |
| `g s` | Sandboxes |
| `g m` | Models |
| `g n` | Nodes |
| `g t` | Live traffic |
| `g l` | Live logs |

## Tabs and dock

| Keys | Does |
|---|---|
| `[` | Previous tab of the page |
| `]` | Next tab of the page |
| `d` | Opens or collapses the dock |

## Tree

Click the tree once to focus it.

| Keys | Does |
|---|---|
| Up, Down | Move through the rows |
| Right, Left | Expand or collapse |
| `Enter` | Open the item |
| `Space` | Select it, for bulk actions |
| `Shift` + click | Select a range |

Selecting rows brings up the bulk bar with actions such as Start, Stop, Restart, Recreate and **Move…**.

## When shortcuts do not work

Single-key shortcuts are off while you type in a text box, a list or the terminal, so they never change what you write there. Only `Esc` still works. Click outside the box, then try again. In a pop-out window (logs or traffic) the shortcuts sheet is not available.
