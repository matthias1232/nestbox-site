# public/help

The in-console documentation: markdown documents the Docs page and the help drawer render (package F18), plus the generated `index.json`.

| File | Role |
|---|---|
| `index.json` | Generated by `node scripts/check-help.mjs`; never edit by hand once F18's script exists. |
| `getting-started.md` | The shell, roles, first sandbox. |
| `tenant-tree.md` | Organisations, data centers, sites; who sees what. |
| `nodes.md` | Adding, draining, deleting nodes; tunnel and egress lock. |
| `deploy-a-model.md` | One model on one node, providers, grants. |
| `deploy-on-many-nodes.md` | The twenty-node example. |
| `model-cluster-round-robin.md` | Clusters, strategies, using one in a sandbox. |
| `policies.md` | Four sections, hot vs recreate, wizard, drafts. |
| `mounts.md` | Persistent roots, RO/RW, Apply now. |
| `egress-modes.md` | Modes, CA, windows, recording. |
| `workbox.md` | The end user's page. |
| `live-logs-and-alerts.md` | Logs, panes, red lane, alert answers. |
| `moves.md` | Preflight, steps, rollback, recover. |
| `shortcuts.md` | Keyboard shortcuts. |
| `glossary.md` | Terms. |

Each document starts with a front matter block (`title`, `slug`, `tags`, `anchors`). Images must be under `/illustrations/`; links to other documents are `/docs/<slug>`.
