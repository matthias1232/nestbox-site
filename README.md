# nestbox-site

Source of the Nestbox website, documentation and appliance services.

## Control Center

The console is organised as a Control Center: one tree of data centers, sites, nodes and sandboxes
with three views (infrastructure, workloads, models), search, bulk actions, model clusters, node
operations and live alerts. Read `docs/guides/control-center.md`; what it does not do is in
`docs/architecture/scope.md`.
